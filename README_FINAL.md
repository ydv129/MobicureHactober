# MobiCure

## URLs

- App: http://localhost:3000
- Tools: http://localhost:3000/tools
- About: http://localhost:3000/about
- Settings: http://localhost:3000/settings
- Contact: http://localhost:3000/contact

## Install

```bash
npm install
npm i -D oxlint
pip install -r services/requirements-minimal.txt
```

## Run

```bash
npm run dev
npm run build
npm start
```

## API

- POST /api/tools/apk-analyzer
- POST /api/tools/url-threat-scanner
- POST /api/tools/email-phishing-detector
- POST /api/tools/image-metadata-scanner
